# Tailmantic UI Component Playground

An independent interactive test bench for the local `packages/ui-components` workspace package. The catalog, demo pages, state, and interactions are implemented inside this app; it does not import implementation or demo code from the documentation example.

## Run locally

```sh
npm install
npm run dev
```

Use the searchable component catalog to open a component, then interact with its controls and component-specific test cases. The playground links to `packages/ui-components`, so component changes are available locally without publishing a new package version.

## Build

```sh
npm run build
```
